# 🎬 Netflix Data Analysis — Pandas, Matplotlib

This project explores and analyzes a Netflix dataset using powerful Python libraries such as Pandas, and Matplotlib. The goal of the analysis is to understand content distribution, trends in release years, ratings and other key insights that shape Netflix's catalog.

# 📌 Project Overview

Performed exploratory data analysis (EDA) on Netflix titles.
Cleaned and prepared the dataset by handling missing values, inconsistent formats, and date parsing.
Extracted important features such as release year, content type, duration, and genre categories.
Used Pandas for data manipulation, grouping, filtering, and statistical summaries.
Applied NumPy for numerical computation and efficient array operations.
Created insightful data visualizations using Matplotlib to reveal trends and patterns.

# 📊 Key Insights

- Distribution of Movies vs TV Shows
- Popular category frequencies
- Release year trends across decades
- Content ratings distribution
- Duration analysis for movies & seasons for TV shows
- Country-wise content contributions

# 📈 Visualizations

- The analysis includes multiple charts such as:
- Bar plots
- Pie charts
- Line plots
- Scatter plots
- Histograms
These visuals help highlight key patterns in Netflix’s content library.
